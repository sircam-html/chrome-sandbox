# <img src="https://www.google.com/chrome/static/images/chrome-logo.svg" alt="Chrome" width="28" style="vertical-align: middle"/> Transient Google Chrome Flake

Nix flakes for personal use, it streams, updates, and executes Google Chrome inside an isolated user-data sandbox bubble. This Flakes allows to run Chrome completely on-the-fly using Nix or NixOS systems.
